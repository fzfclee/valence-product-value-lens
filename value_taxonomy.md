# Value Taxonomy v0.2

## 1. Final Economic Outcomes

Use one primary outcome.

### Grow

Increase revenue, contribution profit, or cash inflow.

Typical signals: qualified traffic, leads, conversion, orders, repeat purchase, customer coverage, channel expansion.

Directional formula:

```text
Incremental contribution profit
= impacted base × incremental conversion or order lift × unit contribution margin × attribution to confirm
```

### Save

Reduce or avoid cost and resource consumption.

Typical mechanisms: direct cost reduction, avoided future spend, productivity, duplicate-build avoidance, lower support burden.

Directional formulas:

```text
Direct saving = baseline actual cost - new actual cost
```

```text
Productivity value
= active value users or annual volume × verified net labor time saved × loaded labor cost × realization factor to confirm
```

### Protect

Reduce revenue loss, risk loss, or business interruption loss.

Typical mechanisms: customer-asset protection, revenue leakage reduction, security, compliance, continuity, trusted official presence.

Directional formula:

```text
Expected loss reduced
= potential economic impact × baseline probability × expected reduction to confirm
```

## 2. Value Mechanisms

A mechanism explains how value might be realized. It is not a final monetary category.

| Mechanism | Typical Economic Outcome | Evidence Examples |
|---|---|---|
| Productivity | Save; sometimes Grow | time saved, task volume, active value users |
| Experience / Service Quality | Grow, Save, or Protect | completion, complaints, waiting time, retention |
| Decision Quality | Grow, Save, or Protect | changed action, cycle time, affected business metric |
| Branding / Official Presence | Grow or Protect; sometimes Save | official search coverage, qualified visits, referral, conversion |
| Time Criticality | Grow loss avoided, Save cost avoided, or Protect | real deadline, value decay, missed-window exposure |
| Risk Reduction | Protect | impact range, probability/risk tier, control effect |
| Platform / Reuse | Save or Protect; attributed Grow only with evidence | downstream consumers, reuse, duplicate builds avoided |
| Learning / Validation | Save or Protect; future Grow option | assumption tested, wrong investment avoided, next decision |
| Strategic Capability | Downstream Grow / Save / Protect | capability use, supported scenarios, reusable assets |

## 3. Tie-Breakers

- Conversion, orders, and customer action → Grow.
- Actual vendor, license, material, or budget reduction → Save / direct saving.
- Labor time reduced without spend removal → Save / productivity value, not direct saving.
- Uncertain downside event → Protect.
- Live-operation interruption → Protect / continuity.
- Reusable platform → Save / reuse first; do not claim all downstream revenue.
- Brand presence → Grow or Protect only when a consumer or channel path is clear.
- Strategic or learning claim with no monetary path → Unvalidated Value Hypothesis.

## 4. Classification Rule

Select:

1. one Primary Audience;
2. one Primary Economic Outcome;
3. one main Value Mechanism;
4. at most one secondary mechanism when the evidence is independent.

Do not create a long list of possible value paths. The purpose is to identify the next evidence and monetization step.
