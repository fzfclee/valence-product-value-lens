# Security Policy

Valence Product Value Lens is a Markdown-first repository and does not run a hosted service or collect user data.

## Supported Version

Security fixes are applied to the latest commit on `main`.

## Reporting A Vulnerability

Use GitHub's private vulnerability reporting:

https://github.com/fzfclee/valence-product-value-lens/security/advisories/new

Include the affected file, the risk, reproduction steps, and a suggested mitigation when available. Do not include confidential product, company, customer, or personal data.

For methodology questions or normal documentation issues, use a public GitHub issue instead.
